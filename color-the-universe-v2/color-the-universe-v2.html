How JWST images are built

Every iconic JWST photo starts as separate monochrome layers. Here is how light becomes art.

1

Capture infrared light

JWST's NIRCam instrument records brightness at specific infrared wavelengths. Each filter is like a color window: it only lets one slice of light through at a time. The detector captures a single grayscale image per filter pass.

F090W 0.9μm F200W 2.0μm F444W 4.4μm
2

Assign visible colors

Since human eyes cannot see infrared, scientists assign each wavelength band a visible color — typically shorter wavelengths get blue, middle ones get green, and longer (warmer) ones get red. This is called false-color imaging and it makes invisible structures visible.

Short → Blue Mid → Green Long → Red
3

Composite and calibrate

Image processors at STScI align, stack, and adjust each layer's brightness to create a final RGB composite. Choices about which colors to assign, and how bright to set each band, are artistic and scientific decisions — which is exactly what you are making in this studio.

🔭

About the image data

The band layers used in this studio were derived from real JWST Early Release Observation images sourced from the MAST Archive via NASA's public image library. The images are processed into simulated single-band grayscale layers (F090W short-IR, F200W mid-IR, F444W long-IR) to demonstrate authentic infrared compositing. All JWST data is in the public domain (NASA/ESA/CSA). The next version of this studio will integrate live FITS file parsing via astropy for true per-pixel band data.
